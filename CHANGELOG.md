# Changelog

JETCARP's changelog is a page of its book, so it has one home:

- **Online:** [jprodgers.github.io/jetcarp/about/changelog.html](https://jprodgers.github.io/jetcarp/about/changelog.html)
- **In this repository:** [docs/src/about/changelog.md](docs/src/about/changelog.md)

Every release, newest first, with what was fixed, changed and added, in the style of
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Each release on
[GitHub](https://github.com/jprodgers/jetcarp/releases) also lists its own changes.
