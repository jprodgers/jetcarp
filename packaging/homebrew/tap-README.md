# JETCARP for Homebrew

```sh
brew tap jprodgers/jetcarp
brew install jetcarp
```

or, in one line, `brew install jprodgers/jetcarp/jetcarp`.

JETCARP @VERSION@: cellular automata on almost any tiling of the plane. See
<https://github.com/@REPO@> and the book at <https://jprodgers.github.io/jetcarp/>.

**This repository is generated.** `Formula/jetcarp.rb` is written by JETCARP's release workflow
from `packaging/homebrew/jetcarp.rb` in <https://github.com/@REPO@>, with the version and the
release archives' checksums filled in. Edit it there, not here: changes made here are overwritten
by the next release.
