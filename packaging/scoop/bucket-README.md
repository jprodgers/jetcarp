# JETCARP for Scoop

```powershell
scoop bucket add jetcarp https://github.com/jprodgers/scoop-jetcarp
scoop install jetcarp
```

JETCARP @VERSION@: cellular automata on almost any tiling of the plane. See
<https://github.com/@REPO@> and the book at <https://jprodgers.github.io/jetcarp/>.

**This repository is generated.** `bucket/jetcarp.json` is written by JETCARP's release workflow
from `packaging/scoop/jetcarp.json` in <https://github.com/@REPO@>, with the version and the
release archive's checksum filled in. Edit it there, not here: changes made here are overwritten
by the next release.
